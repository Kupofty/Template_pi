# Template_pi
Template_pi is an OpenCPN plugin template for quickly developing your own OpenCPN plugin.
It provides a basic starting point for developing and coding a new OpenCPN plugin.


## Documentation
Available in the online [User Manual](https://github.com/Kupofty/Template_pi/blob/main/manual/modules/ROOT/pages/index.adoc).


## Installation
Install directly through plugin catalogue (**OpenCPN → Options → Plugins**), or download packages from [Cloudsmith](https://cloudsmith.io/~kupoftyopencpn/repos/).

To build from source, see [`INSTALL.md`](INSTALL.md).
