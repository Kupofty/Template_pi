# OpenCPN Plugin Icon Guidelines


## General recommendations
* **Size:** Square (1:1 aspect ratio)
* **Format:** SVG


## Toolbar icons (OpenCPN style)
These colors match the OpenCPN toolbar style guide.

| Element                                 | Color     |
| --------------------------------------- | --------- |
| Background                              | `#282828` |
| Icon / Text                             | `#B4B4B4` |
| Background when plugin window is open   | `#898989` |
